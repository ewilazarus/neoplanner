## OpenSpec planning

This project plans its changes with OpenSpec. The specs and changes are in
{{openspec}}, and the `neoplanner:agent` agent keeps them. Read any of them yourself, but
never write them, and don't run the OpenSpec workflow in this conversation. Send the agent
a request instead, in the format the `neoplanner:contract` skill describes.

- **Have it plan** a change before substantial work that has no change yet. Run it in the
  background, then read the `tasks` and `design` paths its reply gives you.
- **Report progress** in the background as you finish tasks, depart from the design, or
  get blocked. The agent ticks the tasks. Send a revise when the plan itself is wrong.
